# SEO Optimization

## Purpose
Improve search engine discoverability and the presentation of website pages in search results.

## 1. Metadata
Every indexable page should have:
- Unique title.
- Relevant meta description.
- Appropriate canonical URL when necessary.
- Open Graph metadata.
- Social sharing metadata when relevant.

## 2. Heading Structure
- Use one clear primary page heading.
- Maintain logical heading hierarchy.
- Avoid using headings only for visual styling.
- Make headings descriptive.

## 3. Content
- Write useful and original content.
- Use descriptive links.
- Organize content into meaningful sections.
- Avoid keyword stuffing.
- Avoid duplicate content.

## 4. Images
- Use descriptive file names.
- Provide meaningful alt text.
- Optimize file sizes.
- Use appropriate image formats.
- Avoid unnecessary decorative image descriptions.

## 5. Technical SEO
- Configure sitemap.xml when appropriate.
- Configure robots.txt.
- Use correct HTTP status codes.
- Ensure important links are crawlable.
- Configure redirects correctly.
- Avoid broken internal links.
- Use structured data when relevant.

## 6. Performance and Mobile
- Ensure mobile usability.
- Optimize Core Web Vitals.
- Avoid intrusive content obstruction.
- Ensure critical content is accessible to crawlers.

## 7. Verification
- Inspect page metadata.
- Check heading hierarchy.
- Check broken links.
- Validate structured data.
- Inspect sitemap.
- Review indexability.

## Checklist
- [ ] Unique titles.
- [ ] Meta descriptions.
- [ ] Heading hierarchy.
- [ ] Descriptive links.
- [ ] Image alt text.
- [ ] Open Graph metadata.
- [ ] Sitemap when applicable.
- [ ] Robots.txt.
- [ ] Structured data when appropriate.

## Expected Output
A technically sound, accessible, search-friendly website.
