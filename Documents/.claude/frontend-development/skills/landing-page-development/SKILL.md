# Landing Page Development

## Purpose
Create landing pages that communicate value clearly and guide visitors toward a specific action.

## 1. Project Discovery
Before designing:
- Understand the product or service.
- Identify the target audience.
- Identify the target age range when relevant.
- Understand the main conversion goal.
- Identify the primary call to action.
- Review brand identity.
- Identify competitors when requested.

## 2. Landing Page Structure

Use only sections relevant to the project.

### Hero Section
- Clear headline.
- Supporting description.
- Primary call to action.
- Secondary action when useful.
- Relevant hero image or visual.
- Strong visual hierarchy.

### Value Proposition
- Explain the main benefit.
- Communicate what makes the offering valuable.
- Keep messaging clear and concise.

### Features and Benefits
- Highlight important features.
- Explain user benefits.
- Use consistent cards or content layouts.

### How It Works
- Explain the process.
- Use clear steps.
- Avoid unnecessary complexity.

### Social Proof
When genuine information is available:
- Testimonials.
- Customer reviews.
- Case studies.
- Partner logos.
- Verified statistics.

Never invent testimonials, customers, or statistics.

### Pricing
When applicable:
- Clearly display pricing.
- Explain plan differences.
- Highlight important limitations.
- Provide clear actions.

### FAQ
- Address common questions.
- Use accessible expandable components.
- Keep answers concise.

### Final CTA
- Reinforce the value proposition.
- Provide a clear next action.
- Avoid competing calls to action.

### Footer
- Navigation links.
- Contact information.
- Legal links when relevant.
- Social links when relevant.

## 3. Visual Design
- Establish a consistent color system.
- Follow 60-30-10 as a starting point.
- Use up to two font families by default.
- Maintain readable typography.
- Use intentional whitespace.
- Maintain consistent section spacing.
- Use high-quality relevant visuals.
- Maintain consistent card and button styles.

## 4. UI/UX
- Make the primary CTA easy to discover.
- Keep navigation intuitive.
- Use clear content hierarchy.
- Provide hover and focus states.
- Use meaningful animations.
- Implement smooth anchor navigation when appropriate.
- Include a back-to-top button on long pages when useful.
- Avoid excessive visual effects.

## 5. Responsive Design
- Follow mobile-first principles.
- Adapt hero layouts.
- Stack content appropriately.
- Optimize images.
- Ensure mobile navigation works.
- Maintain readable typography.
- Test all important viewport sizes.

## 6. Accessibility
- Use semantic HTML.
- Maintain sufficient contrast.
- Provide image alternatives.
- Support keyboard navigation.
- Use accessible buttons and links.
- Respect reduced-motion preferences.

## 7. Performance
- Optimize hero images.
- Avoid unnecessary animations.
- Lazy-load noncritical images.
- Optimize font loading.
- Avoid unnecessary dependencies.
- Minimize layout shifts.

## 8. SEO
- Unique page title.
- Relevant meta description.
- Proper heading hierarchy.
- Descriptive image alt text.
- Open Graph metadata.
- Canonical URL when appropriate.
- Structured data when relevant.

## 9. Final Checklist
- [ ] Target audience identified.
- [ ] Conversion goal defined.
- [ ] Hero section communicates value.
- [ ] CTA is clear.
- [ ] Content hierarchy is logical.
- [ ] Visual design is consistent.
- [ ] Responsive layouts work.
- [ ] Accessibility considered.
- [ ] Animations are purposeful.
- [ ] Images are optimized.
- [ ] SEO metadata configured.
- [ ] Links and buttons tested.

## Expected Output
A polished, responsive, accessible landing page that communicates the offering clearly and supports its conversion goal.
