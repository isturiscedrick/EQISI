# Visual Hierarchy

## Purpose
Help users understand information quickly by organizing visual elements according to importance.

## 1. Content Priority
Identify:
- Primary information.
- Secondary information.
- Supporting information.
- Optional information.

Make important content easy to discover.

## 2. Typography Hierarchy
- Use clear heading sizes.
- Establish consistent font weights.
- Maintain readable body text.
- Use line height appropriately.
- Avoid excessive font variations.

## 3. Spacing
- Group related elements.
- Separate unrelated sections.
- Use consistent spacing.
- Avoid overcrowded layouts.
- Use whitespace intentionally.

## 4. Alignment
- Maintain consistent alignment.
- Align related components.
- Avoid unnecessary visual shifts.
- Use grid systems when appropriate.

## 5. Contrast
- Highlight important actions.
- Maintain readable text.
- Use accent colors selectively.
- Avoid competing focal points.

## 6. Layout
- Establish a clear visual flow.
- Maintain consistent section structure.
- Position important content strategically.
- Avoid unnecessary decoration.

## 7. Checklist
- [ ] Clear focal point.
- [ ] Logical heading hierarchy.
- [ ] Readable content.
- [ ] Consistent alignment.
- [ ] Appropriate whitespace.
- [ ] Clear calls to action.
- [ ] Balanced layout.

## Expected Output
A clean, understandable interface with intentional visual emphasis.
