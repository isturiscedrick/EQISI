# Frontend UI/UX Standard

## Purpose
Ensure every interface is intuitive, visually consistent, accessible, and easy to use.

## 1. User Research
- Identify the target audience.
- Determine the intended age range.
- Understand technical familiarity.
- Identify user goals and expectations.
- Consider different accessibility needs.
- Design according to actual user requirements.

## 2. Color Standards
- Use the 60-30-10 rule as a starting point.
- 60% dominant color.
- 30% secondary color.
- 10% accent color.
- Maintain sufficient contrast.
- Use semantic colors for success, warning, error, and information.
- Never communicate important information through color alone.

## 3. Typography
- Use a maximum of two font families by default.
- Establish heading hierarchy.
- Maintain readable font sizes.
- Use consistent font weights.
- Maintain appropriate line heights.
- Use responsive typography.

## 4. User Feedback
- Provide confirmation dialogs for destructive actions.
- Use contextual inline validation.
- Show actionable errors immediately when appropriate.
- Provide success feedback.
- Use skeleton loaders for content-heavy sections.
- Provide empty states.
- Provide helpful error states.
- Prevent accidental duplicate submissions.
- Show loading and disabled states when appropriate.

## 5. Navigation
- Maintain clear navigation.
- Highlight active navigation items.
- Use breadcrumbs when necessary.
- Provide clear page titles.
- Keep navigation consistent.
- Add back-to-top controls on long pages when useful.
- Make primary actions easy to find.

## 6. Forms
- Provide visible labels.
- Identify required fields.
- Use appropriate input types.
- Provide helpful validation messages.
- Preserve user input after errors.
- Show submission feedback.

## 7. Content
- Use clear headings.
- Keep paragraphs readable.
- Organize related content.
- Use descriptive buttons and links.
- Avoid unnecessary content.
- Maintain consistent section spacing.

## 8. Interaction
- Provide hover, focus, active, and disabled states.
- Use meaningful interaction feedback.
- Keep interactions predictable.
- Avoid unnecessary animations.
- Respect reduced-motion preferences.

## 9. Checklist
- [ ] Target audience identified.
- [ ] Visual hierarchy established.
- [ ] Color contrast checked.
- [ ] Typography consistent.
- [ ] Navigation intuitive.
- [ ] Feedback states implemented.
- [ ] Forms understandable.
- [ ] Calls to action clear.
- [ ] Responsive behavior verified.
- [ ] Accessibility considered.

## Expected Output
An intuitive, consistent, and user-friendly interface that supports the needs of its intended audience.
